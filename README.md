# Tamil + English Auto Captions (v2)

Fast mode (seconds, best accuracy): get a free key at console.groq.com, then
  PowerShell:  $env:GROQ_API_KEY="your_key"; python app.py
Local mode (no key, slower): python app.py   (WHISPER_MODEL=small for faster, less accurate)
Burn-in needs ffmpeg + Noto Sans Tamil font. .txt/.srt/.vtt need nothing extra.
